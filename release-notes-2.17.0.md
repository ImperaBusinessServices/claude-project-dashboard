## New name: Terminal Project Dashboard

The app used to be called **Claude Project Dashboard**. It now launches Claude Code, Codex, OpenCode, local models through Ollama, and Claude on AWS Bedrock, so the name now covers all of them.

- **Nothing else changes.** Your projects, settings, notes and launch choices stay exactly where they were.
- **Windows:** the update replaces the old program and shortcuts with the new name automatically.
- **Mac:** after dragging the new app into Applications, you can delete the old *Claude Project Dashboard* app.
- **New website:** https://terminal-manager.com (the old claude-manager.com address forwards there).

### Download
- **Windows:** `Terminal Project Dashboard Setup 2.17.0.exe`
- **Mac (Apple Silicon + Intel, signed and notarized):** `Terminal Project Dashboard-2.17.0-universal.dmg`
