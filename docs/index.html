The part that changes everything

It sets the whole thing up — so you can just start.

The hardest part of any project is the blank page: which folder, which terminal, what was I even doing? The dashboard quietly handles all of it.

📂

Opens in the right place — every time

Click a project and Claude Code launches in its own terminal, already in the correct folder, caught up on exactly where you left off. Starting fresh? It creates the project folder and sets everything up for you — no paths to type, no “wait, where did I put that?”

🕸️

A shared memory across every project — Synapse

An Obsidian-style web of memory woven right into your code. Every project quietly remembers itself — and they’re all linked together. So Claude can borrow a detail from one project while working in another, and your projects can build on each other instead of starting cold each time.

What else it does

Built to make Claude Code feel effortless.

No setup, no jargon. Point it at the folder where your projects live, and everything just shows up — ready to open, ready to work.

🚀

One click to launch

Every project becomes a tile. Click it and Claude Code opens right there, in its own terminal, already pointed at the right folder. No typing paths, no remembering where things live.

📊

See what Claude’s been doing

Each project gets a living status report. Tick items off as you go — one click for in progress, another for done — and watch each section’s progress fill in.

Get started

Ready in under a minute.

No accounts, no command line, no fuss. Three steps and you’re in.

1

Download & open

Grab the installer below and double-click it. It installs just for you — no admin password.

2

Click “Run anyway”

Windows shows a blue “unrecognized app” notice. Click More info → Run anyway — it’s safe, just not yet code-signed.

3

Point it at your folder

On first launch, pick the folder where your projects live. That’s it — your tiles appear.
