Every tile, explained

No menus to learn — just buttons that make sense.

Each project sits on its own tile with everything you need one click away. Here’s exactly what each button does.

Launch Claude

Launch Claude

Opens a terminal right inside this project’s folder and starts Claude Code — already caught up on where you left off. No typing paths, no wrong directory.

New: the little ▾ next to it lets you start Codex CLI, OpenCode, or your own command in that project instead — it remembers your pick per project, and the button takes that tool’s colour so you can see what you’re launching at a glance.

CLAUDE.md

CLAUDE.md

Opens this project’s instructions — the standing notes Claude follows for this specific project. Edit it to tell Claude how you like things done.

📊 Status

Status

Opens the project’s status report — a friendly checklist of what’s done, what’s in progress, and what’s next. (More on this just below.)

📁

Open folder

Opens the project’s folder in Windows File Explorer, so you can grab a file, drop something in, or just see what’s in there.

i

The (i) summary

Auto-writes a one-line description of what the project is — so a wall of folders becomes a list you can actually read at a glance.

☑ select

Quick select

Tick the box to pick projects out — handy for archiving a few at once when you’re tidying up.

And across the top:

+ New ProjectCreates a brand-new project folder, set up and ready for Claude — with its memory already in place.
SortOrder projects by Last Modified, Date Created, or Name.
ArchivedTuck finished projects away — flip between Active, Archived, and All anytime.
SearchFind any project by name or by what it’s about.
Global CLAUDE.mdOpen the master instructions Claude uses across every project.

The 📊 Status button

See what’s done — and what’s next.

Claude keeps notes as it works. The status report turns those notes into a clean, clickable checklist you can actually read — and update yourself.

✅

A checklist you can tap through

Click any item to cycle it — once for in progress, again for done, a third time to clear. Every section keeps its own little progress bar. (Try it on the report →)

📝

Notes, decisions & done — all in one place

Scroll the report for the fuller picture: what’s been finished, the decisions you’ve made, and a notes box that saves itself as you type.

Memory, blended

Every project remembers — and they share.

The quiet superpower: your projects don’t start cold. Claude writes its own notes as it works — you never take a note — and every project’s memory is woven together.

🕸️

A memory blend across every project — meet Synapse

The notes write themselves. As Claude works, it keeps its own running notes — what it built, what’s next, what you decided — automatically, with zero effort from you. (Think Obsidian or Notion, except you never have to write anything: the notebook fills itself.) Every project keeps its own memory, and Synapse blends them together — so Claude can borrow a detail from one project while working in another, and your projects build on each other instead of starting from scratch. The files are plain Markdown, so they still open natively in Obsidian, Notion, or any notes app if you want to peek.

🧠

Because the memory lives right next to the code, you can come back weeks later, ask where you left off, and pick up mid-thought.
