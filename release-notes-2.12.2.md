# 🔒 Launch Local AI now really stays local

**Launch Local AI** and **Launch OpenCode** run the same program underneath. That meant you could start Local AI, type `/model`, pick a **paid cloud model** without realising — and quietly start spending money on the button that promises free, private and offline.

Fixed. **Launch Local AI** now offers only the models downloaded on your own computer, so `/model` has nothing else to give it. On a test machine the list went from **117 models down to 6** — every cloud provider gone.

**Launch OpenCode is unchanged** and still shows every model you've set up. So the two buttons now genuinely mean different things:

| Button | What `/model` shows |
|---|---|
| 🖥️ **Launch Local AI** | only what's on this computer — free, private, offline |
| 🟢 **Launch OpenCode** | everything you've set up, cloud included |

There's a short note explaining this in **Settings → Which AI runs when you click Launch**, under the Local AI model dropdown.

Nothing else changed, and nothing you need to do — it just works the next time you click Launch Local AI.

---

### Install

- **Windows** — download `Claude Project Dashboard Setup 2.12.2.exe` and double-click it. Windows will warn you it's from an unknown publisher: click **More info → Run anyway**. That's normal (the app isn't code-signed) and there's no admin prompt.
- **Mac** — download the `.dmg`, open it, drag the app to Applications. It's Apple-signed and notarised, so it opens with no warnings.

Or just grab the latest from **https://claude-manager.com**.
