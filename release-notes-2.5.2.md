## Claude Project Dashboard 2.5.2

### "You are here" tick on the usage bars

The Session and Week usage bars now show a small pink marker for **how far through the current time window you are** — separate from how much you've used.

- **Session bar:** the tick slides across the 5-hour window.
- **Week bar:** the tick slides across the 7-day window.
- Halfway through the window, the tick sits in the middle — so at a glance you can see time-elapsed vs. usage-used.

It's anchored to each window's real reset time, so it always lines up with the "↻" reset countdown next to the bar. The same tick shows in the tray popup.
