## Claude Project Dashboard 2.5.3

### Status report tweaks

- **"Up next" now sits above "Done so far."** Your to-do list is at the top where you'll see it first; finished work is below it.
- **Key links show as tidy tiles.** The links box at the top of a report now lays out each link as its own little card (bold name + description) instead of a plain list — easier to scan when a project has several live pages.
