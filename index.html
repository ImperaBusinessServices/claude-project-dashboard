About Claude Project Dashboard v2.2.1 View on GitHub

A simple app to manage your Claude Code project folders.

New in v2.2.1:

  • "View on GitHub" link — quick way to see the source, file an issue, or browse past releases. Sits next to "Check for updates" up top.
Older updates

v2.2.0:

  • One-click auto-update — click "Check for updates" → if there's a new version, hit "Download & Install" and the app downloads, installs, and relaunches itself on the new version. No email, no manual download.
  • Full changelog when you update — if you're a few versions behind, the popup shows what changed in every version between yours and the latest.
  • Open source on GitHub — code lives at github.com/Remagent001/claude-project-dashboard.

v2.1.x (May 2026):

  • Check for updates button (v2.1.0) — initial version polled a hosted version file. Replaced by the full auto-install flow in v2.2.0.
  • Smarter right-click menu (v2.1.0) — right-click the i badge for summary options; the 📊 Status button for status options; elsewhere on a card for everything.

v2.0.0:

  • 📊 Status button on every project tile — click it to open a pretty status report for the project. The report shows the objective, what's been done so far, what's next (with checkboxes you can tick off), and a notepad area for free-form notes. Reports are built from the project's brain/ folder, so they stay in sync with what Claude knows about the project.
  • Right-click the Status button for more options: Refresh (rebuild from latest brain/ files) and Delete.
  • Customize the look using the "Edit Status Report Template" button below — power users can tweak the HTML template that controls how reports are rendered.

v1.4.0:

  • Auto-create a brain/ folder for new projects — when you click + New Project, the app now sets up a small brain/ folder inside it. That's where Claude keeps notes about what you're working on, so when you come back later you can just say "where were we?" and Claude picks up where you left off. Toggle this on/off below.

v1.3.6:

  • Search — type in the search box at the top to find projects by name OR by what's in their summary. E.g. typing eighteeneightdallas.com jumps to the project whose summary mentions that domain. Press Enter if there's only one match — it'll launch Claude Code in that project. Ctrl+F or / focuses the box. Search ignores Active/Archived view so you find everything.
  • Project summaries — Each tile shows a i badge once a summary exists — hover it to read.
  • Edit Summaries button opens a table where you type one-liners for every project at once. The Auto-fill empty button there pulls descriptions from each project's CLAUDE.md, README, package.json, or last Claude session title.

Buttons on each project card:

  • Launch Claude — Opens a terminal in that project folder and starts Claude Code automatically.
  • CLAUDE.md — Opens (or creates) the CLAUDE.md file for that specific project. This is where you put instructions that only apply to this project, like what tech it uses or specific rules for Claude to follow.
  • Folder icon — Opens the project folder in File Explorer.

Top bar buttons:

  • Change Folder — Pick a different root folder where your projects live.
  • Global CLAUDE.md — Opens the main CLAUDE.md that applies to ALL your projects. This is where you put your personal preferences — how you want Claude to talk to you, general rules, etc.
  • + New Project — Creates a new project folder with a CLAUDE.md ready to go.

What's the difference?

Global CLAUDE.md = Your general house rules (applies everywhere).
Project CLAUDE.md = Rules for one specific project (only applies there).

Project summaries
Type a one-line description for each project. Hover the i badge on a tile to read it. You can also right-click any tile to edit just that one (or have Claude try to auto-generate).
Beep on prompt
Play a sound whenever Claude is waiting for your input (like a yes/no confirmation).
Hit Test to make sure you can hear the beep. If you don't hear anything, check that your system volume is up. The beep only triggers on longer tasks — quick replies won't beep. So if Claude is doing real work (running commands, writing code), you'll hear it when it's done.
Set up brain/ on new projects
When you click + New Project, also create a brain/ folder so Claude can remember what you're working on across sessions.
The brain/ folder holds four small notes Claude updates as you work — what's in flight, what's next, decisions, and a changelog. When you come back to a project, just say "where were we?" and Claude reads them to pick up where you left off.
Memory protocol in global CLAUDE.md
Adds a small section to your ~/.claude/CLAUDE.md so Claude knows to read & update the brain/ files automatically.
Without this, the brain/ folder is just inert files — Claude won't touch them unless told. Toggling off removes the section cleanly (it's wrapped in marker comments).
Status report template
The HTML file that controls how every project's status report is laid out. Power users only — friends can leave this alone.
Note: The app only knows about terminals it launched. If you opened a terminal separately, it won't know about that one. Tracking resets when you close the app. But for normal use it prevents duplicates.
