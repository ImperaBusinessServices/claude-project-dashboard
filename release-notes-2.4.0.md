## v2.4.0 — smarter status reports

**Claude can tick off your checklist.** The status report's click-to-cycle checklist (yellow = in progress → done with a line through it → clear) now stores its state in the project's memory (`brain/next.md`), not just your browser. So when Claude finishes a task it can mark that item done, and you'll see it ticked off the next time you Refresh the report. You still click items yourself exactly as before — your clicks are remembered on top, and when Claude updates the file the file wins so the list always reflects reality.

**New "Links" box at the top.** For projects building several things at once — different web pages, a couple of sites, etc. — Claude can keep a short list of links with a one-line description of each, pinned to the top of the status report. It only appears when there are links to show.

Existing reports upgrade to the new template automatically the next time you open or refresh one — no reinstall needed.
