## Sort your projects by AI

A new **AI** button sits alongside the other **Sort by** buttons. Click it and your projects group by whichever AI their Launch button starts — Claude Code first, then Codex CLI, OpenCode, and any custom commands. Click it again to flip the order.

Since Launch buttons are already colour-coded per AI, sorting this way lines the colours up in bands. Inside each group, projects are listed A–Z.

## 🧠 Other AIs now understand your project notes

If you've been launching Codex or OpenCode in a project, they had no idea what your **brain/** folder was for. Shortcuts like *"where were we?"* just confused them — those tools can't read `CLAUDE.md`, which is where the explanation lives.

Now, launching a non-Claude AI in a project writes an **AGENTS.md** — the instructions file those tools *do* read — explaining the memory system and the shortcuts. So your notes, status reports, and "where were we?" work the same whichever AI you open the project with.

- It **never overwrites** an existing `AGENTS.md` — it adds to it, once.
- It only happens if you have **project memory switched on** in Settings.

### Worth knowing

- **Spend tracking still only counts Claude.** It reads Claude's own logs, so Codex sessions cost money that won't appear on the chart. Same for the usage meters — those stay Claude-only.
